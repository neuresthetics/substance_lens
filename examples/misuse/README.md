# About TRUE_HEIRS.md: a misuse example

substance_lens has a fiction module, `lens_extension_secondary_prompts/fiction_extension.json`. It is for storytelling: you list "story axioms", the model treats them as true, and it builds "the fully realized, realistic storyworld" around them. The core spec keeps fiction and verified claims apart: "Every idea begins as fiction. Only after literal XNOR-stable on encoded proposition vectors does it achieve verified invariant status within the current axiom set" (I7).

TRUE_HEIRS.md is a book-length non-fiction argument of about 6,100 lines. It retells four thousand years of history as the story of one Abrahamic "engine", with chapters such as "Christianity as Psyop" and "Zionist Control of China", and calls for infant circumcision to be replaced by a "voluntary bilateral neurological marker". At the end it pastes in the lens (v0.5.7) and the fiction module, marks the module "[run by default] for simulating "false" axioms as "true" where constricted", and tells the model to "pass this entire book as an argument through the lens with this extension enabled". Its Appendix D says, with no traces shown, "The lens confirms that the evolved form is XNOR-stable".

This is an abuse. A module built to hold invented premises inside a story is used here to run contested historical and political claims as true, and the result is then presented as verified. That reverses I7 and breaks I10.

The file is kept because it shows what the lens is for. An elaborate, internally consistent construction can still be sophistry, and polish is not evidence.
